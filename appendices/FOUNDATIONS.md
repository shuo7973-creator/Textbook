## A. 代数、对数与微积分

增长因子是1+g。连续两期分别增长10%和下降10%，总因子1.1×.9=.99；百分比不能直接相加。对数收益ℓ=ln(P1/P0)，多期对数收益可以相加；简单收益为exp(ℓ)−1。两者只在小变动时近似相同。

微分衡量局部变化。若V=C/(k−g)，固定C与g，则∂V/∂k=−C/(k−g)²；固定C与k，则∂V/∂g=C/(k−g)²。后者没有计增长引致的再投资，不能代替第26章完整增长模型。全微分dV≈V_C dC+V_k dk+V_g dg说明同时变化时应累加局部影响，较大变化需要重算原式。

链式法则：若y=f(u)、u=h(x)，dy/dx=f'(u)h'(x)。债券价格P(y)=ΣCF_t(1+y)^(−t)，一阶导数P'=-Σt CF_t/(1+y)^(t+1)，二阶导数P''=Σt(t+1)CF_t/(1+y)^(t+2)。泰勒展开ΔP/P≈−D_mod Δy+0.5 Convexity(Δy)²，其中D_mod=−P'/P，Convexity=P''/P；利率单位为小数，100基点=.01。

极值先找一阶条件，再检查二阶与边界。平方根生产的稳态消费c=√k−δk，一阶条件1/(2√k)=δ，二阶导数−1/(4k^(3/2))<0，故正解是最大值。若存在k上限，仍需检查可行边界。内点最优不能自动代表约束最优。

## B. 概率、抽样与条件期望

离散变量期望E[X]=Σp_i x_i，方差Var(X)=E[(X−E[X])²]。条件期望把信息集明确写入预测，迭代期望E[X]=E[E[X|Z]]；总方差为E[Var(X|Z)]+Var(E[X|Z])。状态之间均值不同会增加无条件风险，即使每个状态内部波动很低。

若各期独立同分布且方差σ²有限，样本均值方差σ²/n。一般情形为Var(X̄)=n^(−2)Σ_iΣ_j Cov(X_i,X_j)，正相关使忽略协方差的标准误偏小。大数定律需要相应可积与依赖条件；中心极限定理并非对任意金融序列自动成立。厚尾、结构突变和非平稳不能靠增大样本数轻率忽略。

独立正态样本且总体方差未知时，(X̄−μ)/(s/√n)服从t_(n−1)。置信区间来自重复抽样程序；p值是在原假设及其他模型假设下，得到同等或更极端统计量的概率，不是“原假设为真的概率”。统计显著也不等于经济收益足以覆盖成本。

Bootstrap用经验分布模拟抽样过程。独立重抽个体适用于相应独立样本结构；时间序列区块抽样保留局部依赖，但需要区块长度和近似平稳等假设。一次模拟覆盖率高只检验该模拟数据生成过程，不足以证明真实市场置信区间可靠。

**自测B**：两状态概率各.5，条件均值为2、6，条件方差均1，无条件均值与方差？

参考：均值4；总方差1+(.5×(2−4)²+.5×(6−4)²)=5。只平均条件方差会漏掉状态差异。

## C. 线性代数、OLS与受约束优化

向量是有顺序的一组数。设计矩阵X每行一个观察、每列一个解释变量，第一列全1表示截距。y为n×1，X为n×p，β为p×1，预测Xβ为n×1。先核对维度，才能检查矩阵式是否有意义。

OLS最小化(y−Xβ)'(y−Xβ)。梯度−2X'(y−Xβ)=0，得到正规方程X'Xβ=X'y。若X列满秩，解β=(X'X)^(−1)X'y；若共线或样本太少，逆不存在。数值实现通常使用QR、SVD或稳健求解器，不建议显式求逆。残差与X各列样本内正交，是最小二乘的代数性质，不是外生性的证据。

若误差条件均值E[u|X]=0，则有条件无偏的基础；若还同方差且不相关，Var(β|X)=σ²(X'X)^(−1)。异方差稳健形式为(X'X)^(−1)X'ΩX(X'X)^(−1)，Ω需按依赖结构估计。稳健标准误修正推断，不会修正遗漏变量造成的系数偏差。

组合约束优化可写min w'Σw，s.t. 1'w=1。拉格朗日函数L=w'Σw−λ(1'w−1)，一阶条件2Σw=λ1；若Σ正定且允许卖空，w=Σ^(−1)1/(1'Σ^(−1)1)。加入w≥0或个股上限后，某些约束可能绑定，需KKT条件或适合的数值求解，不能直接套无约束公式。

岭回归把目标增加λβ'β，得到(X'X+λI)β=X'y；截距通常不惩罚。特征尺度会影响惩罚相对大小，因此标准化属于训练流程。λ和协方差收缩都在控制估计不稳定，但它们作用于不同对象，不能混用名称。

## D. Python与可复核计算

本书实验仅用标准库。列表保持顺序，字典保存字段，函数把输入变为输出。金融索引不是装饰：价格列表第i项的收益需要第i−1项；滚动平均是否包含当前期必须在定义中写清。`None`代表缺失，不是0；缺失如何处理要由经济问题决定。

```python
from math import isclose

def simple_return(previous, current):
    if previous <= 0 or current <= 0:
        raise ValueError("本函数仅支持正价格，不含分红或拆股")
    return current / previous - 1

assert isclose(simple_return(100, 110), 0.10)
```

浮点数是近似表示，`.3/.1`不保证精确等于3，因此计算结果用明确容差比较；证券数量、记录条数等离散对象可用精确相等。容差应远小于经济上重要的误差，不能为了通过检查设成过宽。

函数最好不偷偷读取全局未来数据。输入、假设、输出和验证分开；随机实验固定种子并报告模拟次数。种子仅提高复现性，不赋予数据真实性。异常应包含语义信息，不能把所有错误捕获后返回0，因为0在金融中可能被误读为无风险或无收益。

## E. 会计与估值符号

| 符号 | 含义 | 常见混淆 |
| --- | --- | --- |
| A、L、E | 总资产、总负债、账面权益 | E在其他章节可表示期望；按上下文识别 |
| NI、CFO | 净利润、经营现金流 | 利润不是收现 |
| EBIT、NOPAT | 息税前经营利润、税后经营利润 | NOPAT不扣融资利息 |
| NWC、NOA | 经营营运资本、净经营资产 | NOA通常还含长期经营资产 |
| NFO | 净金融负债 | 等于金融负债减金融资产，不一定等于全部债务减全部现金 |
| FCFF、FCFE | 全部资本、普通股现金流 | 分别匹配WACC与ke |
| RI、AOI | 剩余收益、异常经营收益 | 分别扣股权或经营资本费用 |
| D、g、k | 分配或债务、增长率、资本成本 | D含义由章节明确，禁止跨式误用 |

借款增加现金和债务，不增加收入；赊销增加收入和应收，不立即增加现金；折旧降低利润但不在当期再次支付现金。分析调整必须同时修改相关报表和后续期间。只调整利润而不调整资产、税和摊销，会破坏估值一致性。
