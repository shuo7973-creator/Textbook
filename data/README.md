# 第1章数据字典

所有数据均为原创假设数据，没有真实公司、政策公告或证券价格。本实验用于比较条件情景，不估计现实政策效果。

输入：[ch01_scenarios.json](ch01_scenarios.json)。估值时点Y0年末，Y1—Y3为未来三个完整年度；金额为人民币亿元，股数为亿股，输出每股价值为元/股。收入、EBIT、折旧、资本开支为年度流量；营运资本为各年经营结束、清算前的期末存量。

| 字段 | 含义与约定 |
| --- | --- |
| revenue | 年度营业收入 |
| ebit_margin | EBIT/收入，已扣折旧，未扣利息和所得税 |
| depreciation | 当年折旧摊销，已含在EBIT费用中，计算FCFF时加回 |
| capex | 当年经营资本开支，正数表示现金流出 |
| operating_nwc | 经营营运资本，排除现金和有息债务；本例假定为收入的20% |
| initial_operating_nwc | Y0年末经营营运资本18亿元 |
| tax_rate | 对正EBIT计算的经营税率25%；本例不处理亏损税收结转 |
| discount_rate | 匹配FCFF的恒定年度名义人民币资本成本；10%或9%为设定值，不等于政策利率 |
| terminal_recovery | Y3经营现金流之后清算全部经营资产所得的税后净回收40亿元，包含营运资本回收；不再另加营运资本或持续经营终值 |
| debt_at_valuation | Y0有息债务价值20亿元，假设账面值等于市场值 |
| excess_cash_at_valuation | Y0非经营性富余现金5亿元；不在经营现金流或回收值中 |
| shares | Y0普通股10亿股，假定无稀释、无优先股与少数股东权益 |

## 模型边界

这是三年后终止经营的现有企业。估值计算未来可分配给全部资本提供者的现金流，不是新投资的NPV，故没有额外扣除Y0历史投资。Y3正常经营仍计入营运资本增量，随后清算才回收，不能重复加回。

清算回收40亿元是各情景的共同外生假设；营运资本不同意味着其余经营资产的回收贡献相应不同。此约定用于隔离持续经营现金流与折现率影响，不能解释为真实企业清算价值不受景气影响。真实研究还需分别估计应收回收、库存处置、固定资产残值、税和清算费用。

情景没有概率，不计算概率加权期望价值。基准情景不被称为“最可能”；9%的资本成本也不表示任何实际降息幅度。后续第26章另行讲授持续经营终值。
