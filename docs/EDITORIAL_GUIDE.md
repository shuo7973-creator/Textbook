# 编写规范与验收标准

## 内容深度

定位为完整系列教材。概念必须给出定义、单位、经济意义、成立条件及至少一个失效边界。重要公式先说明对象，再逐步推导；基础读者能够沿等式重算。采用英文术语辅助检索，但正文以中文解释。

每章有5—8个可观察学习目标；核心推导、完整例题、机制反例、练习及答案相互对应。篇幅由主题决定，不设置凑字数要求。理论章不强制伪造可交易策略，数据实验也不自动称为实证发现。

## 统一结构

1. 元信息：章号、状态、先修、核心/进阶、预计学习方式。
2. 开场问题与学习目标。
3. 定义与经济机制。
4. 公式推导、假设和边界。
5. 完整计算例题。
6. 中国或A股应用中的口径与证据要求。
7. 数据或量化实验及解释任务。
8. 本章总结、下一章接口、参考阅读。

练习和答案分别存储，采用稳定编号CHxx-Eyy。每题给出难度、预计用时、分值、已知条件和交付要求。答案先提示，再完整推导，最后给评分点。开放题允许不同结论，但必须能追溯证据和假设。

## 财务与数据口径

- 金额注明币种与量级；增长率与百分点分开；名义与实际量分开。
- 报告期、发布日期、入库时间、修订版本、信号和交易时间分别记录。
- 会计恒等式、行为方程与估值定义分别命名；恒等式不能直接识别因果。
- 利润、CFO、FCFF、FCFE按各自口径定义；现金流与折现率匹配。
- 企业价值到权益价值的桥接逐项核对；任何简化必须列出忽略项目。
- 模拟数字、真实历史数据、假设预测和模型输出在表头或说明中明确区分。
- A股交易规则及费用在相关章发布时核查有效日期与适用板块，不硬编码成永久规则。

## 代码与实验

默认实验可离线运行；真实数据下载为显式可选步骤。数据源、许可、覆盖范围与校验信息单独记录。Notebook负责讲解与交互，共用计算放入模块。避免在Notebook和正文分别维护不同公式。

每个实验都有可手算的基准例、预期关系和错误用法对照。验证涵盖真实风险：时间泄漏、单位不一致、现金流漏算、非法参数、重复扣减、依赖顺序。代码运行成功不代表金融模型正确或存在alpha。

## 章节验收

| 项目 | 验收要求 |
| --- | --- |
| 概念 | 关键定义、对象、单位与边界完整 |
| 理论 | 重要公式推导可追踪，简化条件明确 |
| 案例 | 输入、输出、期间、单位和模型范围一致 |
| 练习 | 8—12题分层；每题在答案册有对应条目 |
| 计算 | 例题与代码交叉核对，精度与舍入有说明 |
| 数据 | 来源或模拟标签、可用时间、字段口径可核查 |
| 编辑 | 链接有效，术语统一，无未填占位符冒充正文 |
| 结论 | 对照组、替代解释、证据不足与负结果得到保留 |

## 参考一致性审校

每批交付一份“主张—参考位置—实际可访问内容—假设—独立检查—剩余缺口”记录。版本固定到地区版及可查ISBN，中文译本按章名映射。仅查目录时不得宣称已查教材正文；原创推导、例题与程序不得冒称参考教材原文。统计与程序方法使用原始论文、作者公开教材或官方文档补充，不强行归入四本金融主教材。

重要推导逐项核对定义、符号、单位、量纲、时点、成立条件和失效边界。答案使用独立手算或不同计算路径复核，不能从待测函数反推期望值。发现概念问题须同步修改正文、题答、实验与受影响交叉引用；尚未解决的问题单列，不用笼统“全部核验通过”掩盖。

## 问答课堂规则

每次只问一道开放题。学习者先答，教师指出正确点与遗漏，再给提示或追问；必要时用小计算题要求复述。正确答案不只看数值，还看口径、假设和机制。只有实际作答、练习与退出题通过，才记录掌握；定时提醒或教材更新不改变进度。
