# 制作与发布状态

## v0.1：规划与样章

交付40章详细规划、先修关系、模板、项目任务书与第1章完整样章。版本完成要求是文本、题答、数据和计算能相互核对，不以文件数量代替教学质量。

本版本供检查理论深度、推导密度、案例难度和练习体验。第2—40章只有教学设计，没有用占位正文标记完成。

## v0.2：全书初稿

按读者确认的继续全部39章要求，将原分批安排合并为一次全书初稿交付。第2—40章均有原创正文、5项目标、8题及独立提示答案、可执行Python与Notebook。全书共40章、324题、40份Notebook。新增数学/统计/Python/会计附录、连续财报案例及来源索引。

本版覆盖宏观、货币金融、公司理财、财报与估值、基本面量化主干。进阶主题展开程度不同：矩阵OLS、约束优化等有附录推导；树模型、区块bootstrap和完整市场撮合以方法与边界说明为主，未声称已有完整软件实现。原课程总纲保留进一步深化的范围。

## v0.3：分八批深化

按每批五章推进完整系列教材深度。前七批第1—35章已增加机制推导、条件与反例、分层题答和分步实验；全书现有460题。每批同时交付参考一致性核验表和计算验证记录，明确目录核对与全文核验的区别。详见[深化进度](ITERATION_V03.md)。其余5章不因生成器重新运行而标记深化完成。
