# 制作与发布路线

## v0.1：规划与样章

交付40章详细规划、先修关系、模板、项目任务书与第1章完整样章。版本完成要求是文本、题答、数据和计算能相互核对，不以文件数量代替教学质量。

本版本供检查理论深度、推导密度、案例难度和练习体验。第2—40章只有教学设计，没有用占位正文标记完成。

## 教材制作状态

第1章：样章完成并经本版本记录中的检查。第2—40章：规划中。真实企业案例：待选定与整理。真实横截面数据：待核验可得性与历史版本。现有样例全部为假设数据。

## 阅读反馈

评价样章时优先记录：哪个推导跳步、哪个符号不明确、哪道题信息不足、哪个答案无法复核。教学设计调整同步到模板和已完成章节。
