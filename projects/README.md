# 阶段项目与毕业项目任务书

本页为项目设计。v0.2已有40章离线模拟实验，第40章提供端到端最小模拟；以下P1—P6与毕业项目的真实数据研究仍待实施。真实数据研究完成与否须有数据和运行证据，不能以目录存在判断。

## 通用提交包

每个项目提交：研究问题、事前假设、数据字典、来源与时间口径、方法与基准、代码或计算表、结果、替代解释、限制、改判条件。真实数据记录报告期/事件时间、available_at、版本与样本覆盖。模拟数据保持明确标签。

## P1 中国宏观观察

- 先修：2—10，14选读。问题：增长与通胀的主要驱动是什么，证据是否一致？
- 数据：统计局等官方发布；选择GDP、价格、生产、消费、投资与就业的有限指标，保留定义与发布日期。
- 步骤：统一口径→绘制时间线→比较支持与矛盾证据→提出基准和替代情景。
- 交付：指标字典、可更新图表、1000—1500字简报与三项验证指标。
- 验收：不得用数据修订后的历史值冒充实时判断；能解释至少两处指标背离。

## P2 利率与信用传导

- 先修：11—15。问题：一次政策变化通过哪些环节影响企业融资？
- 数据：央行发布、可核查债券利率与公司债务披露；明确政策预期与公告信息差别。
- 步骤：事件时间线→曲线与利差→企业固定/浮动利率及期限结构→现金流影响。
- 交付：收益率曲线分析、传导图、两类企业的敏感性比较。
- 验收：政策利率、无风险利率、信用利差与WACC分开；没有识别条件不声称因果。

## P3 企业财务诊断

- 先修：16—24。问题：企业盈利来自哪里，能否持续转化为现金和资本回报？
- 数据：一家非金融主案例和两家同行至少三个完整年度的公开财报及附注。
- 步骤：业务拆解→三表底稿→经营/融资重构→盈利与周转→质量疑点→同行比较。
- 交付：历史模型、来源索引、两页诊断和待核查问题清单。
- 验收：原始数可追溯、勾稽成立、异常有解释；不能只凭红旗指认不当行为。

## P4 企业估值

- 先修：25—30。问题：什么经营与资本回报假设支持目前价值判断？
- 数据：沿用P3，设定明确估值基准日及当时已披露信息；市场价格与股数同日或说明差异。
- 步骤：驱动预测→三表→FCFF/FCFE→资本成本→稳态→价值桥接→剩余收益或倍数对照→反向估值。
- 交付：五年简化预测、至少两种方法、敏感性、三个情景和研究报告。
- 验收：同预测下方法差异可解释；增长与再投资相容；固定项与不可识别性公开。

## P5 基本面多因子

- 先修：31—38。问题：价值与质量信号在控制行业、规模和成本后是否仍有证据？
- 数据：真实PIT财务、历史股票池、总回报与公司行动；若不可得，只做模拟实验并列缺口。
- 步骤：事前协议→按时点取数→因子→分组与IC→基准→组合→成交/成本账本→滚动检验。
- 交付：研究协议、因子字典、账本、样本外结果、试验清单与负结果。
- 验收：没有未来信息、当前成分回填或测试集调参；成本与不可成交情况有处理依据。

## P6 宏观条件与策略表现

- 先修：14、15、33、38；39为可选扩展。问题：宏观条件能解释或预测因子差异吗？
- 数据：按公布与修订时点组织宏观信息，结合P5因子收益；优先少量有机制依据的状态变量。
- 步骤：定义状态和窗口→只用训练期估计阈值→比较无条件基准→样本外评估→稳定性与成本。
- 交付：条件表现、状态误判分析、参数敏感性与结论边界。
- 验收：把事后描述与事前可预测分开；样本不足或状态不稳定也应作为结果。
- 选做：公告事件标签与人工复核；必须区分文本分类质量与投资价值。

## 毕业项目

选择一个有明确机制的研究问题，例如“融资条件改善对不同营运资本占用企业的影响”。将宏观解释、企业预测、估值与可检验信号串联；不要求一定形成有效策略。

提交：宏观简报、企业报告、研究协议、数据与模型、验证结果、复现入口及反方审阅。若使用真实数据，给完整取数口径；若数据不足，用模拟实验说明方法并限制结论。

评分100分：机制20、数据口径20、财务/估值一致性20、验证设计20、复现与表达20。出现未来信息或不可追溯核心数据，须修正后再验收。正收益不是通过条件。
