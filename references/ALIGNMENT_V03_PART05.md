## 跨章修正：连续案例现金分类

原稿将利息支付后的经营现金中间量21.5/26.775标为CFO，却未说明制度；这与本书中国一般企业主线不一致。现统一支付借款利息列筹资，所得税均在本期支付并列经营，保留全部底层现金和利润假设。

| 项目（亿元） | Y1历史教学 | Y2基准预测 |
| --- | ---: | ---: |
| NI | 19.5 | 23.175 |
| CFO，支付利息列筹资 | 25.5 | 28.875 |
| CFI | −10 | −12 |
| CFF，含利息及股利 | −7 | −8.1 |
| 期末现金 | 18.5 | 27.275 |
| 利息税盾，CFO到FCFF需扣除 | 1 | .525 |
| FCFF | 14.5 | 16.35 |

第21章补直接法收付145−113−6.5=25.5，第22章改为FCFF=CFO−利息税盾−资本开支，第25章同步全部现金和预测桥，附录F同步。原21.5/26.775仅能作为已付利息后的分析现金中间量，不再冒称当前案例报表CFO。主表直接列示与附注间接调节也已分清。历史版本验证记录保留原事实，由本表标明后续修正。

另修正原第22章“现金从NOA排除再加回就重复”的不严谨概括：从经营价值到权益价值加回一次融资现金本来必要；错误是已扣NFO又加同一现金，或现金收益未剥离却重复估值。
