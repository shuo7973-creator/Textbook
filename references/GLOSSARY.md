# 第1章术语表

| 术语 | 本书含义与口径 |
| --- | --- |
| 事实 / observation | 有来源和时点的观测，可能存在误差及修订 |
| 假设 / assumption | 为推理设定的条件，需注明依据与边界 |
| 恒等式 / identity | 定义或核算上必然成立的关系，不自动识别因果 |
| 机制 / mechanism | 从变化到结果的行为和约束路径，需要证据 |
| 信息集 / information set | 特定决策时点已可得的信息集合 |
| PIT / point-in-time | 按当时可得版本组织数据，避免事后修订倒灌 |
| EBIT | 未扣利息和所得税、已扣相关经营费用及折旧的利润 |
| NOPAT | 按明确税口径计算的税后经营利润，不是归母净利润 |
| 经营NWC | 经营流动资产减经营流动负债；本例排除现金与有息债务 |
| FCFF | 融资前、供全部资本提供者的自由现金流 |
| 资本成本 | 与现金流风险、币种和口径匹配的要求回报；不等于政策利率 |
| 经营资产价值 | 经营现金流及经营资产回收的现值 |
| 权益价值 | 在明确桥接规则下归属于普通股股东的价值 |
| 情景分析 | 对不同条件输入计算结果，本身不估计发生概率或因果效应 |
| 样本外检验 | 用未参与拟合或选择的数据评价事先确定的方法 |
