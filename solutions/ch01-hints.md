# 第1章提示

先尝试[练习册](../workbook/ch01.md)，再按需要阅读相应提示。完整过程在独立[答案册](ch01.md)。

| 题号 | 提示 |
| --- | --- |
| CH01-E01 | 区分“文件确实这样写”和“未来收入真的会这样发生”。观察结果也带有抽样不确定性。 |
| CH01-E02 | 共同需求与融资条件属于一个层次，竞争、技术替代和份额属于另一个层次。 |
| CH01-E03 | 对等式取变化：其他三项为什么可以或不可以当成不变？ |
| CH01-E04 | 先计算每年的营运资本增量；Y3回收在年末只加一次。 |
| CH01-E05 | 建立三个节点：基准、仅降资本成本、低资本成本加弱经营。 |
| CH01-E06 | 25%乘的是期末收入，对第一年增加额仍减Y0的18。 |
| CH01-E07 | 报告期末不是公开可得时间，公开时间也未必等于系统收到时间。 |
| CH01-E08 | 实际收益使用实际成交/价格路径，不使用估值目标当作未来价格。 |
| CH01-E09 | 对$(1+k)^{-t}$求导；若唯一支付是未来义务，符号会怎样？ |
| CH01-E10 | 先列V00、V01、V10、V11，交互为V11−V10−V01+V00；同类贡献在两个顺序中取平均。 |
| CH01-E11 | 明确“意外”的可观测定义，以及处理组为什么可能与对照组本来就不同；Y(0)是同一主体未受处理的潜在结果。 |
| CH01-E12 | 先固定经营看贴现率，再固定贴现率改变经营；两种操作回答不同问题。 |
