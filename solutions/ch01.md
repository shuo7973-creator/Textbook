# 第1章参考答案与评分依据

对应[练习册](../workbook/ch01.md)。所有计算都基于本章假设数据，金额亿元；每股价值元。展示值保留六位小数，计算中不提前舍入。开放题按论证与条件评分，不要求文字相同。

## CH01-E01 四种句子的性质（6分）

1. “文件设定收入100”是对文件内容的事实性陈述；但其中“未来收入100”在经济分析中属于假设。能区分这两层最重要（2分）。
2. 固定非负现金流下的折现率方向是模型推论，需要$k>-1$等定义条件（2分）。
3. 属于附有不确定性的实证结论。正的样本均值并不能消除估计误差；区间包含零意味着按相应区间方法无法排除零效应，不能改写为已证明有效（2分）。

常见错误：把模拟输入当成观测事实；把统计不显著等同效应一定为零。

## CH01-E02 总量到企业（6分）

宏观层面可排查内外需、融资条件、投资意愿和库存周期；行业层面可排查下游结构、产品替代、供给过剩、竞争与订单季节性。每层给出合理原因及证据线索，各2分。

企业偏离平均可来自客户结构、份额变化、产品升级、交付瓶颈或特定大客户订单。给两个合理原因合计2分。只列宏观指标名称、不说明如何关联订单，不得满分。

## CH01-E03 恒等式与因果（8分）

变化恒等式为$\Delta Y=\Delta C+\Delta I+\Delta G+\Delta NX$。单独令$\Delta G=10$并不足以决定$\Delta Y$；必须知道其他分项反应（2分）。

挤出情景：资源紧张且融资条件收紧，政府支出增加10，私人投资减少6，其余不变，则产出增加4。这组数字只是满足设定的例子，不是实证乘数（2分）。

闲置产能情景：政府需求增加带动就业和收入，居民消费增加3、其余不变，则产出增加13；额外消费必须由明确行为机制支持。也可以用有进口泄漏的其他合理设定（2分）。

两情景都满足恒等式。分歧在行为反应和约束，而非核算是否成立（2分）。

## CH01-E04 基准现金流与价值（12分）

| 项目 | Y1 | Y2 | Y3 |
| --- | ---: | ---: | ---: |
| EBIT | 15 | 16.5 | 18.15 |
| NOPAT | 11.25 | 12.375 | 13.6125 |
| ΔNWC | 2 | 2 | 2.2 |
| FCFF | 7.25 | 8.375 | 9.4125 |

EBIT与NOPAT计算2分，营运资本增量2分，FCFF2分。

$$V_0=7.25/1.1+8.375/1.1^2+(9.4125+40)/1.1^3=50.636739.$$

现金流时点与回收折现2分。$E_0=50.636739-20+5=35.636739$，$v_0=3.563674$元/股（2分）。

40已经包含经营营运资本回收，再加24.2会重复计入；NOPAT未扣融资费用、也未按归母等权益口径调整，不是归母净利润。两点各1分。

若错误地把Y0历史资产投入再扣一次，会把现有企业价值与新投资NPV混淆。

## CH01-E05 降息与需求疲弱（10分）

固定基准现金流，只将资本成本改为9%：

$$V_{rate}=7.25/1.09+8.375/1.09^2+49.4125/1.09^3=51.855962.$$

需求疲弱情景：每年EBIT为10.8、NOPAT为8.1、ΔNWC为0，所以FCFF每年6.1（2分）。

$$V_{weak}=6.1/1.09+6.1/1.09^2+46.1/1.09^3=46.328237.$$

两项估值合计3分。先利率后经营：

- 利率贡献：51.855962−50.636739 = +1.219223。
- 经营贡献：46.328237−51.855962 = −5.527726。
- 总变化：−4.308503。

分解3分。资本成本、收入和利润率路径是设定；FCFF、价值及其差额是条件计算结果，不是现实降息的因果估计（2分）。

## CH01-E06 增长与资金占用（10分）

| 项目 | Y1 | Y2 | Y3 |
| --- | ---: | ---: | ---: |
| NOPAT | 12.48 | 13.92 | 15.60 |
| NWC，20% | 20.80 | 23.20 | 26.00 |
| ΔNWC，20% | 2.80 | 2.40 | 2.80 |
| FCFF，20% | 7.68 | 9.52 | 10.80 |
| NWC，25% | 26.00 | 29.00 | 32.50 |
| ΔNWC，25% | 8.00 | 3.00 | 3.50 |
| FCFF，25% | 2.48 | 8.92 | 10.10 |

两组现金流计算4分，尤其第一年增量仍减18，不能减新比例下假想的Y0金额。

20%情景价值为54.285586，25%情景价值：

$$V_{25\%}=2.48/1.09+8.92/1.09^2+50.1/1.09^3=48.469407.$$

价值变化为−5.816179（3分）。

保持总回收40表示增加的营运资本清算回收与其他资产净回收贡献合计仍须为40，不能再额外加回营运资本。如果假设新增营运资本在清算时额外全额回收，必须同时修改总回收输入，结论数值会变化。真实库存增加可能有不同回收、坏账、销售和税影响，不能把此计算推广成固定损失（3分）。

## CH01-E07 检查信息时间（8分）

报告期表示经济活动所属期间，不代表数据在该期末已公开。4月18日收盘早于20:00公开和20:05收到时间，当日收盘信号用了未来信息（3分）。

修正：保留报告期与available_at；系统研究再保留入库/处理完成时间；只在全部输入处理完后的信号中使用该版本。随后根据实际交易日历、停牌和适用交易规则选择可执行时点；未来修订不回填历史（3分）。

不能仅机械shift一个自然日：周末、假日、停牌和处理时延都可能改变实际可用或可成交时点（2分）。

## CH01-E08 价值与收益（8分）

假设按8元买入、7.5元卖出，无分红与费用，持有收益$(7.5-8)/8=-6.25\%$（2分）。真实交易还需计费用。

估值差价不保证短期收益，原因包括：现金流或资本成本假设错误；价值实现慢于持有期；新的负面信息；估值差异可能是对风险的补偿；交易成本或流动性约束（任意三个合理原因3分）。

预先明确股票池与可得信息、信号定义、持有期与调仓、基准、风险控制、成本、样本外窗口和评价指标；给出至少三类并解释其作用（3分）。

## CH01-E09 推导与边界（8分）

$$V(k)=\sum_{t=1}^{T}C_t(1+k)^{-t}.$$

逐项应用幂函数及链式求导：

$$V'(k)=\sum_{t=1}^{T}C_t[-t(1+k)^{-t-1}]=-\sum_{t=1}^{T}\frac{tC_t}{(1+k)^{t+1}}.$$

推导3分。$k>-1$、现金流固定、每项非负且至少一项为正，是严格为负的充分条件（2分）。

反例：只有一年末义务$C_1=-100$，$V=-100/(1+k)$，$V'=100/(1+k)^2>0$。折现率增加使负债现值的负数绝对值缩小（2分）。最后强调这里是固定现金流的偏导数，政策变化可能同时改变现金流（1分）。

## CH01-E10 改变归因顺序（8分）

先改变经营、资本成本保持10%：

$$V_{weak,10\%}=6.1/1.1+6.1/1.1^2+46.1/1.1^3=45.222389.$$

因此先经营后利率的两项贡献为：

- 经营：45.222389−50.636739 = −5.414350。
- 利率：46.328237−45.222389 = +1.105847。
- 合计：−4.308503。

单一顺序数值2分。总差由终点减起点决定，顺序不改变总差；利率对不同现金流的现值影响不同，所以单项归因不同（2分）。

交互项以未舍入四角点计算约−0.113376（2分）。对称分解：利率贡献约$(1.219223+1.105847)/2=1.162535$；经营贡献约$(-5.527726-5.414350)/2=-5.471038$；合计仍为−4.308503（2分）。展示值舍入可能造成末位差异。该对称分解是归因约定，也不是政策因果识别。

## CH01-E11 设计一个真实研究（8分）

一种可接受的协议：选择预先固定时期内的A股非金融企业，按事件前已经披露的债务到期和浮动利率暴露形成高低组，保留退市样本。用公告前可得的市场预期区分预期内动作与意外变化；分别检验短期风险调整收益和随后季度融资成本。比较同行业、相近规模和经营风险的企业，检查事前差异。控制同期需求和风险溢价变化；独立保留样本外事件。如果方向不稳定、控制后消失或经济幅度不足，拒绝原假设或缩小适用范围。

没有预期数据时，只能研究“政策公告附近的关联”或条件差异；不能把政策动作本身等同外生意外冲击。事件研究也不会自动解决同期新闻、预期形成和样本选择。

反事实定义：同一家企业在同一时期、没有该政策冲击而其他背景依相应研究设定演化时的结果Y(0)。它不是事后随意选取的同行，也不是直接观测到的另一个值；比较对象用于在额外假设下估计它。该句纳入原“限制结论”评分，不增加总分。

评分：样本和时点2分；暴露与事件定义2分；结果窗口和比较1分；两项混杂1分；失败条件1分；限制结论1分。不同方法可得满分，前提是识别假设与数据要求明确。

## CH01-E12 实验与反方复述（8分）

基准经营固定时：

| 年资本成本 | 经营资产价值（亿元） |
| ---: | ---: |
| 8% | 53.118411 |
| 9% | 51.855962 |
| 10% | 50.636739 |
| 11% | 49.458864 |
| 12% | 48.320555 |

复核和记录2分。读者自行修改经营参数，必须说明输入、输出和其余固定项；机制与计算一致3分。可用E06中的营运资本变化，但应指出期末回收假设。

合格反方复述：这些数值表明在本例的正支付条件下，固定现金流降低资本成本会提高模型价值；经营恶化可抵消这一影响。本例没有真实政策、风险溢价、公司行为或市场收益观测，不能证明降息的因果影响。真实检验需当时可得财报、政策预期、历史样本及价格，并处理混杂、交易条件和样本外验证。

对推论和证据边界解释3分。允许报告负结果和与预期相反的修改实验，只要可复核。

## 退出验收

核心题建议达到50/68分，并修正E04中的重复计入和E07中的前视问题后再推进。分数用于发现薄弱点；不能只凭总分覆盖关键口径错误。最后口头复述一条宏观—经营—财务—价值链，并说出一个会改变判断的观测。
